模型从共享盘读取，未改写或复制 9B 权重。bootstrap 检查已确认厂商模块可导入、Qwen3.5 配置可解析。

## 已验证场景

1. 图片：红色圆形、蓝色矩形；模型返回期望的两个颜色字段。
2. 文档页：合成票据图片；正确提取 `INV-2026-0042`、`CNY`、`1234.50`。
3. 工具：模型自主调用 `get_order_status`，CPU 读取示例订单，模型根据结果返回 `ready_to_ship` 和 `source=demo`。
4. 鉴权：不带令牌的 `/v1/models` 请求被拒绝，带令牌可查询正确模型别名。
5. 媒体访问：未授权的远程图片域名被拒绝；正常图片通过 Base64 传入。
6. 进程管理：`stop` 成功关闭本项目整个进程组，重新 `start` 保留原有令牌。

图片场景先验证服务未启动时请求失败；CPU 文档客户端和工具示例均先经历缺少实现的失败，补齐后通过真实 HTTP 验收。
首版标准库 CPU 示例的回归使用 `python -S` 禁用第三方 site-packages；此记录不适用于下述迁移后的 SDK 客户端。

## 已知限制与后续

- 当前后台进程不具备开机自启、故障自动恢复或平台级访问控制配置。
- CPU 跨服务器访问 8000 的网络入口尚待用户确认；GPU 本机通过不代表平台已开放该端口。
- 暂不实现 PDF 拆页/文字提取、跨页检索、完整文档管理或真实业务系统接入。
- 目前仅验证合成英文票据字段和中文指令；实际中文扫描件、复杂表格和小字需要用户样本验收。
- 当前为 eager、低并发配置；尚未做高并发、长上下文、多模型同卡负载测试，不启用 MTP 或量化。
- 厂商日志可能提示 `VLLM_KV_DISABLE_CROSS_GROUP_SHARE` 未在通用环境变量表登记；本项目按厂商文档保留该设置。
  另有 CoreX 扩展的 Dynamo 跟踪/重编译警告；本次功能已通过，不把警告消失当作验收目标，也未修改厂商源码。

进入下一阶段优先使用实际图片/文档样本和一个只读业务 API 验证；再按实测延迟决定是否优化图像尺寸、并发、上下文或 CUDA Graph。
