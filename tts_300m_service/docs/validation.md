通过统一 WSS 提交三个分段时，三段都在首段完成前得到 `input.accepted`，音频严格按 FIFO 返回。
WSS 首 PCM 为 5.780 秒，三段总耗时 28.071 秒。活动段取消会清空等待队列并保持连接可复用；
本次取消等待底层生成器清理 12.455 秒，确认后没有额外 PCM。

服务监控样例为 `running`、2254.438 MB；最近 60 秒 GPU 首 token 平均 282.577 ms、P95
1152 ms。该指标从 GPU 内部 LLM 推理到首 speech token，不含队列、PCM 生成与网络，因此不同于
客户端首 PCM。新进程启动后窗口从空计数开始，未继承原服务直方图。

公开入口的无 key/错误 key 均返回 HTTP 401。正常日志未发现提交文本或固定指令。以上数值只描述
该次 BI150 验收，不是延迟承诺。

默认把 `tts` 映射到 `tts_300m_service`，运行进程的 cwd、解释器、配置和内部 key 路径都位于该目录。

时，需要同时重启 monitor，并 reload 网关。客户端首 PCM 与监控的 GPU 首 token 口径不同。

## 2026-09-18 固定单音色与中文数字

默认推理固定使用 `中文女`、英文 instruction 和随机种子 42。客户端不能提交音色或 instruction；
checkpoint 中其他 speaker 名称只用于启动时校验模型制品，不会成为运行时选项。英文 instruction
真机合成后未被朗读；固定种子用于降低不同分段间的随机音色和语调漂移。

最终 Instruct 运行态用两段不同中文数字文本复核，CAMPPlus speaker embedding 余弦相似度为
0.846104，ASR 结果只包含请求正文，没有英文 instruction。同一正文重复合成的 PCM 并非逐字节一致，
因此固定种子只能降低随机漂移，不能作为波形完全确定性的保证。

阿拉伯数字统一经过中文文本规范化。真机通过统一 WSS 合成“今天是2026年9月18日，温度23.5度，
完成率12%。”，再用本机 ASR 复核，最终文本为“今天是二零二六年九月十八日，温度二十三点五度，
完成率百分之十二。”。该次冷请求首 PCM 19.832 秒，输出 303616 字节，总耗时 24.207 秒。
完整服务、CPU 客户端与契约测试共 53 项通过，环境与模型制品检查通过。
