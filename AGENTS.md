# Project agent policy

- Do not use the Superpowers plugin or any `superpowers:*` skill in this repository.
- Do not use the Wolfram plugin, its app/MCP tools, or any Wolfram-provided skill in this repository.
- Do not create Superpowers planning or scratch artifacts under `.superpowers/` or `docs/superpowers/` for new work.

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the five default canonical labels. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses the single-context layout. See `docs/agents/domain.md`.
